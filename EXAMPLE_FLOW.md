# Example: hello-world build

1. Launch Aura with `python aura_app.py`.
2. Enter: `Aura, create a hello world Python app`.
3. Aura creates `hello-world/PLAN.md`, `hello-world/README.md`, and `hello-world/hello.py`.
4. Aura auto-runs the safe Python syntax validation.
5. Aura displays an approval dialog before running the new script.
6. Approve it. Aura captures `Hello from Aura!` and reports success in chat; every action appears in the log.
